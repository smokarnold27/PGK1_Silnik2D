Detailed Description

Abstrakcyjna klasa bazowa dla obiektow wymagajacych aktualizacji.

Definiuje wspolny interfejs umozliwiajacy aktualizowanie stanu obiektow podczas dzialania aplikacji.

Udostepnia metode Update(), ktora moze byc wykorzystywana do aktualizacji polozenia, animacji lub innych elementow stanu obiektu.

Metoda aktualizacji jest czysto wirtualna, dlatego jej implementacja nalezy do klas pochodnych.

Note
Klasa wykorzystuje wirtualne dziedziczenie po GameObject, aby uniknac wielokrotnego wystepowania tej klasy bazowej w hierarchii dziedziczenia.
