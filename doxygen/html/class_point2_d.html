Detailed Description

Klasa reprezentujaca punkt w przestrzeni dwuwymiarowej.

Przechowuje wspolrzedne punktu w postaci liczb zmiennoprzecinkowych oraz jego kolor.

Umozliwia pobieranie i modyfikowanie wspolrzednych, rysowanie punktu oraz wykonywanie transformacji geometrycznych, takich jak przesuwanie, obracanie i skalowanie.
