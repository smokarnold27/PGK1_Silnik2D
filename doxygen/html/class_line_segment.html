Detailed Description

Klasa reprezentujaca odcinek w przestrzeni dwuwymiarowej.

Odcinek jest okreslony przez dwa punkty koncowe, kolor oraz algorytm wykorzystywany do jego rysowania.

Klasa umozliwia rysowanie odcinka z wykorzystaniem algorytmu DDA lub Bresenhama, a takze wykonywanie transformacji geometrycznych, takich jak przesuwanie, obracanie i skalowanie.

Rysuje odcinek za pomoca wybranego algorytmu.

Parameters
rendererReferencja do renderera odpowiedzialnego za rysowanie.

Metoda rysuje odcinek pomiedzy jego punktami koncowymi, wykorzystujac przypisany kolor i algorytm rysowania.

Dla wartosci LineAlgorithm::DDA wykorzystywany jest algorytm przyrostowy DDA. W pozostalych przypadkach wykorzystywany jest algorytm Bresenhama.
