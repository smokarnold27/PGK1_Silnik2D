\doxysubsection{Detailed Description}
Klasa reprezentujaca prostokat w przestrzeni dwuwymiarowej. 

Przechowuje punkt odniesienia prostokata, jego szerokosc, wysokosc, kolor oraz informacje o wypelnieniu.

Umozliwia rysowanie prostokata wypelnionego lub jego konturu, a takze wykonywanie transformacji geometrycznych.

Boki prostokata pozostaja rownolegle do osi ukladu wspolrzednych.

\begin{DoxyNote}{Note}
Obracanie prostokata zmienia polozenie jego punktu odniesienia, ale nie orientacje bokow. 
\end{DoxyNote}
