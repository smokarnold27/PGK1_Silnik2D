\doxysubsection{Detailed Description}
Abstrakcyjna klasa bazowa dla obiektow wymagajacych aktualizacji. 

Definiuje wspolny interfejs umozliwiajacy aktualizowanie stanu obiektow podczas dzialania aplikacji.

Udostepnia metode \doxylink{class_updatable_object_ae13f789087044ce65835a495c0dabd9b}{Update()}, ktora moze byc wykorzystywana do aktualizacji polozenia, animacji lub innych elementow stanu obiektu.

Metoda aktualizacji jest czysto wirtualna, dlatego jej implementacja nalezy do klas pochodnych.

\begin{DoxyNote}{Note}
Klasa wykorzystuje wirtualne dziedziczenie po \doxylink{class_game_object}{Game\+Object}, aby uniknac wielokrotnego wystepowania tej klasy bazowej w hierarchii dziedziczenia. 
\end{DoxyNote}
