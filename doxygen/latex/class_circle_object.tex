\doxysubsection{Detailed Description}
Klasa reprezentujaca okrag w przestrzeni dwuwymiarowej. 

Umozliwia tworzenie i rysowanie okregow o okreslonym srodku, promieniu, kolorze oraz sposobie wypelnienia.

Obiekt obsluguje transformacje geometryczne, takie jak przesuwanie, obracanie i skalowanie.
